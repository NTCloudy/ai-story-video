Privacy Policy – Shorts Uploader

Last updated: October 16, 2026

Shorts Uploader ("the app") is a personal automation tool operated by the owner of the GitHub repository NTCloudy/ai-story-video. It generates short educational videos and uploads them to the owner's own YouTube channel.

Data we access

  • With your explicit consent via Google OAuth, the app uses the YouTube Data API scopes youtube.upload (to upload videos to your channel) and youtube.readonly (to read your channel name and statistics).
  • The app does not access any other Google account data.

How data is used and stored

  • The OAuth refresh token is stored only as an encrypted GitHub Actions secret in the owner's repository and is used solely to upload videos the owner generated.
  • No personal data is sold, shared with third parties, or used for advertising.
  • The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Use of YouTube data is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

You can revoke the app's access at any time at myaccount.google.com/permissions. Deleting the GitHub secret also removes the stored token.
