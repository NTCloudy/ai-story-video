Privacy Policy – Shorts Uploader / Cloud Auto Poster

Last updated: October 18, 2026

Shorts Uploader and Cloud Auto Poster ("the app") are a personal automation tool operated by the owner of the GitHub repository NTCloudy/ai-story-video. It generates short educational videos and publishes them to the owner's own YouTube channel, Facebook Page and Instagram professional account. It has no other users.

Data we access

  • YouTube – with explicit consent via Google OAuth, the app uses the YouTube Data API scopes youtube.upload (to upload videos to the owner's channel) and youtube.readonly (to read the channel name and statistics). The app does not access any other Google account data.
  • Facebook and Instagram – with explicit consent via Facebook Login, the app uses the permissions pages_show_list, pages_read_engagement, pages_manage_posts, business_management, instagram_basic, instagram_content_publish and instagram_manage_comments, only for the owner's own Facebook Page and the Instagram account linked to it: to read their names and IDs, publish the owner's videos as Reels, and read the resulting posts.
  • The app does not collect data about any other person, and does not read private messages.

How data is used and stored

  • Access tokens are stored only as encrypted GitHub Actions secrets in the owner's repository and are used solely to publish videos the owner generated.
  • Post IDs and links of published videos are kept in the repository file channel/history.json.
  • No personal data is sold, shared with third parties, or used for advertising.
  • The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube data is also subject to the YouTube Terms of Service and the Google Privacy Policy.
  • Use of Facebook and Instagram data follows the Meta Platform Terms.

Revoking access and deleting data

  • Google: revoke access at myaccount.google.com/permissions.
  • Facebook / Instagram: remove "Cloud Auto Poster" under Facebook Settings & privacy → Settings → Business integrations (or Instagram Settings → Website permissions → Apps and websites).
  • Deleting the GitHub secrets removes every stored token. To have any remaining data deleted, email the address below; it is removed within 7 days.
