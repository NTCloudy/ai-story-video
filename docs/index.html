      📺 怎麼上傳到 YouTube？
      1. 在影片卡片按「⬇️ 影片」和「🖼️ 縮圖」、「💬 字幕」下載檔案
      2. 打開 YouTube Studio → 右上角「建立」→「上傳影片」
      3. 按「📋 複製標題」「📋 複製說明」貼到 YouTube 的標題、說明欄位
      4. 「縮圖」上傳 thumbnail.jpg；「字幕」上傳 subtitles.srt（選「含時間碼」）
      5. 「是否為兒童打造」依內容選擇 → 發布 🎉

      插畫由 AI 生成、旁白為 AI 語音。上傳時建議在 YouTube「變造或合成內容」選項勾選「是」。
